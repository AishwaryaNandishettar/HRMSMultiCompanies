====================================
VERCEL FRONTEND ENVIRONMENT VARIABLES
====================================
Copy these values to Vercel dashboard → Settings → Environment Variables

1. VITE_API_BASE_URL
   Value: https://latestfinalhrmsapplication.onrender.com

2. VITE_API_URL
   Value: https://latestfinalhrmsapplication.onrender.com/api

3. VITE_WS_URL
   Value: https://latestfinalhrmsapplication.onrender.com/ws

====================================
IMPORTANT NOTES:
====================================
- VITE_API_BASE_URL must be your Render backend URL
- After adding these, redeploy your frontend
- Make sure to select "Production" environment when adding variables

====================================
HOW TO ADD IN VERCEL:
====================================
1. Go to: https://vercel.com/dashboard
2. Select your frontend project (HRMS-Frontend or omoi-hrms)
3. Click "Settings" tab
4. Click "Environment Variables" in left sidebar
5. For each variable above:
   - Key: (e.g., VITE_API_BASE_URL)
   - Value: (e.g., https://latestfinalhrmsapplication.onrender.com)
   - Environment: Production (checked)
6. Click "Save"
7. After all are added, go to "Deployments" tab
8. Click "..." on the latest deployment → "Redeploy"
