  HOW TO FIX EMPLOYEE DIRECTORY - SIMPLE STEPS
═══════════════════════════════════════════════════════════════

PROBLEM:
  Frontend shows wrong employees than what's in MongoDB

SOLUTION:
  Run a simple Node.js script to sync companyId

═══════════════════════════════════════════════════════════════

STEP 1: Open Command Prompt (CMD, not PowerShell!)
──────────────────────────────────────────────────────────────
1. Press Windows Key
2. Type: cmd
3. Press Enter


STEP 2: Navigate to Backend Folder
──────────────────────────────────────────────────────────────
cd "d:\New folder\HRMSProject (2)\HRMSProject\HRMS-Backend"


STEP 3: Install MongoDB Driver (one-time)
──────────────────────────────────────────────────────────────
npm install mongodb --no-save


STEP 4: Run the Fix Script
──────────────────────────────────────────────────────────────
node fix_employee_directory_node.js


STEP 5: Wait for Success Message
──────────────────────────────────────────────────────────────
You'll see:
  ✅ All employees now have companyId: 'omoikaneinnovations'
  ✅ All users now have companyId: 'omoikaneinnovations'


STEP 6: Restart Backend
──────────────────────────────────────────────────────────────
1. Stop current backend (Ctrl+C if running)
2. Run: mvn spring-boot:run


STEP 7: Clear Browser Cache
──────────────────────────────────────────────────────────────
1. Open Chrome
2. Press F12
3. Go to "Application" tab
4. Click "Clear site data"
5. Close and reopen browser


STEP 8: Test
──────────────────────────────────────────────────────────────
1. Go to http://localhost:5173
2. Login
3. Go to Employee Directory
4. NOW YOU'LL SEE CORRECT EMPLOYEES!
