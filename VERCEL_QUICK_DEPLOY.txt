================================================================================
  IF LOGIN FAILS ON VERCEL
================================================================================

ISSUE: "Invalid credentials"
CAUSE: VITE_TENANT_ID is set in Vercel
FIX:
   1. Vercel Dashboard → Settings → Environment Variables
   2. Delete VITE_TENANT_ID
   3. Redeploy

ISSUE: "403 Forbidden"
CAUSE: VITE_TENANT_ID is being sent
FIX:
   1. Same as above
   2. Delete VITE_TENANT_ID from Vercel env
   3. Redeploy

ISSUE: "Network Error"
CAUSE: Backend (Render) is sleeping
FIX:
   1. Go to: https://latestfinalhrmsapplication.onrender.com
   2. Wait 30 seconds for it to wake up
   3. Try login again

ISSUE: Shows wrong employees
CAUSE: Browser cache
FIX:
   1. Clear cache (Ctrl+Shift+Delete)
   2. Hard refresh (Ctrl+Shift+R)
   3. Or use Incognito (Ctrl+Shift+N)
